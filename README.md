First Response Training App

An augmented reality training app designed to provide users with basic-level emergency medical knowledge through real-world simulations. The app integrates gamification elements, such as drag-and-drop activities, scenario-based learning, and quizzes to make the learning process engaging and interactive.

Features
	•	Real-World Simulations: Provides users with practical emergency medical scenarios.
	•	Gamification: Interactive elements like drag-and-drop activities, quizzes, and scenario-based challenges to enhance engagement.
	•	AR Integration: Utilizes ARKit and SceneKit to bring the learning experience to life with augmented reality.
	•	User-friendly Interface: Built using UIKit and SwiftUI for smooth navigation and interaction.

Technologies Used
	•	ARKit
	•	SceneKit
	•	UIKit
	•	SwiftUI

Installation
	1.	Clone the repository: https://github.com/harsh7987/First-Response-Training-.git
  2.	Open the project in Xcode.
	3.	Run the project on a physical device (AR features may not work properly on simulators).

Usage
	•	Launch the app to start with basic-level emergency medical training.
	•	Engage with different learning modules that cover essential medical procedures.
	•	Complete quizzes and activities to test your knowledge.
